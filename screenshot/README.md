# ARCHON Visual Checkpoint Index

This folder is the persistent UI review history for ARCHON.

Each UI-affecting checkpoint must create a subfolder following:

```text
YYYYMMDD-HHMM_<checkpoint>_<short-sha>/
```

Every update folder contains:
- `manifest.json`
- `REVIEW.md`
- `desktop/*.png`
- `mobile/*.png`

See `docs/11_UI_SCREENSHOT_PROTOCOL.md` for the authoritative capture and review protocol.
